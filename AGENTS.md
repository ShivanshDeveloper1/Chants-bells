# Chants & Bells — Project Instructions

## Project

Build a premium spiritual/wellness website for **Chants & Bells**, focused on devotional products, spiritual practices, and customers looking for authentic religious items.

## Tech

* Next.js App Router
* TypeScript
* Tailwind CSS
* Framer Motion
* Lucide React
* Server Components by default
* Client Components only when interaction requires them

**Important:** TypeScript is already configured in the project. Do not spend time explaining, redesigning, or changing TypeScript unless required for the task.

## Design

* Premium
* Calm
* Spiritual
* Minimal
* Modern Indian aesthetic
* Mobile-first
* Subtle animations only
* Avoid clutter

## Colors

* Background: `#F8F5EC`
* Foreground: `#14251C`
* Gold: `#B98225`
* Light Gold: `#D9AD55`
* Lotus Red: `#8E211C`
* Muted: `#6F7168`
* Surface: `#FFFDF7`
* Border: `#E5DCC8`

Use off-white as the main background, dark green for text, gold for primary highlights/CTAs, and lotus red sparingly.

## Typography

Use an elegant serif for major headings and a clean sans-serif for body text.

## Components

* Keep sections modular and reusable.
* Do not create one huge component.
* Reuse existing components where possible.
* Do not rewrite working code unnecessarily.

## Responsive

Every section must work properly on:

* Mobile
* Tablet
* Desktop

Prioritize the mobile experience.

## SEO

Build the website with **SEO and search intent** in mind.

Target people actively searching for spiritual and devotional products, especially during **Navratri and other Hindu festivals**.

Use natural search-intent phrases where relevant, such as:

* Navratri puja items
* Navratri पूजा सामग्री
* Navratri devotional products
* Durga puja items
* पूजा सामग्री
* धार्मिक सामान
* spiritual products
* devotional products
* पूजा के सामान

Do not keyword-stuff.

Focus SEO on:

* Clear page titles
* Useful meta descriptions
* Semantic headings
* Descriptive URLs
* Internal linking
* Product/category content
* Image alt text
* Fast loading
* Mobile performance
* Structured, helpful content

Create dedicated festival/category content only when it provides genuine value to users.


## Website Sections

Include where appropriate:

* Hero
* About
* Services/Products
* Devotional/Festival sections
* Testimonials
* Contact
* Payment/CTA

## Code Quality

* Keep code simple and readable.
* Avoid unnecessary dependencies.
* Follow existing project patterns.
* Prefer simple solutions over over-engineering.
